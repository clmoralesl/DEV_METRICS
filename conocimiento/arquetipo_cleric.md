# Arquetipo Cleric (calidad, correccion y revision)

El Cleric sana el software y protege a los demas. Su actividad se concentra en corregir errores,
revisar pull requests ajenos, escribir pruebas y gestionar issues: bug fixes, hotfix,
regresiones, revisiones con cambios solicitados o aprobaciones, pruebas automaticas.

Senales en GitHub: mensajes de commit de correccion, revisiones de pull requests de otras
personas, archivos de pruebas e issues atendidos. Se asigna a proyectos de estabilizacion,
mejora de calidad y soporte de servicios criticos. El perfil de cada persona es una mezcla de
arquetipos con nivel de confianza, no una etiqueta unica.
